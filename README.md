# Mein Dokument-Reader – PWA-Dateien

Enthalten sind:

- `index.html`
- `manifest.webmanifest`
- `service-worker.js`
- `.nojekyll`
- `icon-192.png`
- `icon-512.png`

Alle Dateien müssen mit derselben Ordnerstruktur veröffentlicht werden.
Die Reader-Bibliothek liegt weiterhin lokal in IndexedDB des jeweiligen
Browsers und wird nicht in dieses Projekt hochgeladen.
